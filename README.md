# Breeze Breathe

By **BREEZE QORVA** · package `com.breezeqorva.breezebreathe` · Expo owner `mini55`.

Paced breathing for Android that works fully offline.

## Screens
1. **Breathe.** One orb that fills as you breathe in, waits while you hold and empties as you breathe out, with the phase and seconds inside it and a ring for the session. Pick 1–15 minutes; sessions round to whole breaths. Pause, resume or finish early.
2. **Patterns.** Coherent (5.5 · 5.5), Box (4 · 4 · 4 · 4), 4 · 7 · 8, Long exhale and Wake up, each with a timing bar, plus your own pattern built from four steppers.
3. **Sounds.** Ocean, rain and brown noise faders, all generated by Web Audio on the phone, with presets and a preview. They play during sessions.
4. **Journal.** Streak, minutes this week, a seven-day chart and every session.
5. **Settings.** Session length, bell between phases (higher on in, lower on out), vibration at each phase so you can close your eyes, keep the screen on, Dusk or Dawn look, clear journal, reset.

The session keeps running if you switch tabs. Going to the background or pressing back pauses it. While a session runs the shell keeps the screen on with `expo-keep-awake` (no permission needed).

## Code
`web/src/lib/breath.ts` is pure and tested (15 tests): phase timing, orb fullness, session rounding, streaks and the save. Fonts are Instrument Serif and Onest.

## Identity, About and privacy
- The app name, version and company come from `app.json` (`expo.name`, `expo.version`, `expo.extra.company`). The header, welcome tour, About page, confirm cards and store art all read them, so a rename needs no code change.
- Settings → About and privacy shows the name, version and maker, and the full privacy policy, readable offline.
- Android back on the first screen asks before leaving the app.
- The welcome tour, empty states and celebrations are Lottie scenes generated in code from the theme palette (`web/src/lottie/`). Reduce motion swaps them for still frames.
